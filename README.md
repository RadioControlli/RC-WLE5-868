This SDK supports RC-WLE5-868 and RC-WLE5-434
There are two versions :
- STM32Cube_FW_WL_V1.3.0_TCXO    for the version with TCXO
- STM32Cube_FW_WL_V1.3.0_XO      for the version with XO

If you download the SDK directly from st.com you can use the patch : STM32Cube_FW_WL_V1.3.0_patch_20230831
About the different frequency version (433,868,915MHz) no need to do any settings just change the frequency to use.
